■ 怎麼跑 / 怎麼測(起手式)
     npm install
     npm run dev            # 兩專案都是 Vite
   約拿:
     npm test               # 內容/語法/狀態機/嵌入契約(~2 秒)
     npm run test:offline   # 再加 build + PWA 離線就緒
     npm run build          # = 逐檔複製到 site/(不是 vite build)
   保羅:
     npm test               # validate(全旅程)+ selfplay(各 1200 場)+ 煙霧
     npm run test:offline   # build + dist 離線就緒(Workbox 預快取逐檔檢查)
     npm run test:browser   # Playwright 實機(需先起 preview)
     npm run sync:jonah     # 同步約拿引擎
     npm run gen:map        # 動站點經緯度後重生地圖
