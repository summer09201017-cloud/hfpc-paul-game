■ 兩個專案怎麼關聯(很重要)
  「保羅大富翁」是外框(桌遊);「約拿闖關」是上游的小遊戲引擎。
  保羅的 src\minigames\jonah\ 是約拿引擎的純複製 copy:
     在保羅資料夾跑  npm run sync:jonah  即一鍵同步最新引擎(不必手動重套)。
  嵌入契約(寫在約拿 CLAUDE.md,改引擎前必讀):
     • ui 由外部注入(單機 new UI() / 嵌入 NullUI 或 EmbedUI),game.js 不 import ui.js
     • opts.embed=true 走嵌入分支;白名單 level 1~6
     • 1/2/4 純 Canvas 關:配空殼 NullUI 即可
     • 3/5/6 卡片流程關:保羅 MiniGameModal.jsx 的 makeEmbedUI 把
       showFish*/showPreach*/showGourd* 畫成 React 卡片,按鈕回呼 handleXxxAction
  上線節奏(牧師定的):新功能一律 feature branch + 測試全綠 → 牧師實測
  → 說「滿意請 merge」才 merge main(約拿 main = Netlify 自動部署)。
  牧師的實測回饋通常很短(一句話),要從經文脈絡理解意圖再動手。

■ 怎麼跑 / 怎麼測(起手式)
     npm install
     npm run dev            # 兩專案都是 Vite;保羅常占 5173,約拿會跳 5174
   約拿:
     npm test               # 煙霧測試:內容/語法/狀態機/嵌入契約(零相依,~2 秒)
     npm run test:offline   # 再加 build + PWA 離線就緒(sw 預快取/manifest)
     npm run build          # ⚠ 不是 vite build!(agape250 那台 Node 24 地雷,見 CLAUDE.md)
   保羅:
     npm run validate       # 內容驗證(journey JSON)
     npm run test:selfplay  # 引擎自我對戰(三旅程各 1200 場)
     npm run test:browser   # Playwright 實機測試(需先起 preview/dev server)
     npm run sync:jonah     # 同步約拿引擎
