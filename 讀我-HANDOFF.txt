■ 怎麼跑 / 怎麼測(起手式)
     npm install
     npm run dev            # 兩專案都是 Vite;保羅常占 5173,約拿會跳 5174
   約拿:
     npm test               # 煙霧測試:內容/語法/狀態機/嵌入契約(零相依,~2 秒)
     npm run test:offline   # 再加 build + PWA 離線就緒(sw 預快取/manifest)
     npm run build          # ⚠ 不是 vite build!(這台 Node 24 地雷,見 CLAUDE.md)
   保羅:
     npm run validate       # 內容驗證(journey JSON)
     npm run test:selfplay  # 引擎自我對戰
     npm run test:browser   # Playwright 實機測試(需先起 preview/dev server)
     npm run sync:jonah     # 同步約拿引擎
